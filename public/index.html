Search uses the YouTube Data API through the Anon Watcher server. A server-side API key is required. Search results can include videos and playlists.

02 / CONTROLS

Simple playback

YouTube videos use YouTube's own player controls through its privacy-enhanced embed. Direct MP4 and HLS URLs use your browser's native video controls.

03 / PRIVACY

Privacy-enhanced embed

YouTube playback is served from youtube-nocookie.com. YouTube may still process data when you play an embedded video. Direct media is played by your browser.
