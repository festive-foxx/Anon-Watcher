01 / SOURCES

Search and watch

Search uses the YouTube Data API through the Anon Watcher server, with an optional browser-only fallback key in Settings. Search results can include videos and playlists.

02 / CONTROLS

Simple playback

YouTube videos use YouTube's privacy-enhanced embed. Space toggles playback, F toggles fullscreen, and M toggles mute; shortcuts are inactive while typing. Direct MP4 and HLS URLs use native controls.

03 / PRIVACY

Privacy-enhanced embed

Watch history, saved items, and an optional API key stay in this browser. YouTube playback uses youtube-nocookie.com; YouTube may still process data when an embed is played.
